# Portfólio Profissional — Diego Rodrigues Miranda

Website de portfólio profissional para apresentar minha trajetória, projetos, experiências e formas de contato. Desenvolvido no Laboratório 01 da disciplina de Desenvolvimento de Interfaces Web (DIW), Ciência da Computação, PUC Minas.

## Descrição do projeto

O site terá quatro seções, acessadas por um menu de navegação:

- **Sobre Mim:** apresentação em português e inglês (botão PT | EN), com formação, interesses e objetivos.
- **Projetos:** linha do tempo com nome, descrição, tecnologias, link do GitHub e imagem ou GIF de cada projeto.
- **Experiências:** estágios, freelas, projetos open source e eventos técnicos.
- **Contato:** ícones clicáveis (e-mail, WhatsApp, LinkedIn) e formulário com envio por e-mail.

## Tecnologias previstas

- HTML5, CSS3 e JavaScript
- Figma (wireframes)
- Git e GitHub (versionamento)
- EmailJS (envio de e-mail pelo formulário)
- Vercel (hospedagem)

## Como executar localmente

1. Clone o repositório: `git clone https://github.com/diegorodrigues261107-byte/portifolio`
2. Abra a pasta no VS Code.
3. Clique com o botão direito em `index.html` e escolha **Open with Live Server** (extensão Live Server), ou abra o arquivo direto no navegador.
